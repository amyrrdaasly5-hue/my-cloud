# شروع پروژه My Cloud

این یک نسخه اولیه (MVP) برای فضای ابری چندکاربره است:
- ثبت‌نام و ورود با ایمیل و رمز عبور
- بارگذاری، دانلود و حذف فایل
- باکت خصوصی و سیاست‌های دسترسی جداگانه برای هر کاربر
- نمایش میزان استفاده و سقف هدف ۱۵ گیگابایت برای هر حساب

## نکته مهم درباره ۱۵ گیگابایت
کد رابط کاربری سقف ۱۵ گیگابایت را نمایش و به‌صورت اولیه بررسی می‌کند؛ این کنترل به‌تنهایی برای سرویس عمومی و قابل سوءاستفاده نبودن کافی نیست. قبل از انتشار عمومی باید سهمیه ۱۵ گیگابایتی در سمت سرور/پایگاه داده به شکل اتمیک اعمال شود، محدودیت نوع/اندازه فایل، rate limit، تأیید ایمیل، بازیابی رمز و پایش هزینه‌ها راه‌اندازی شود. هر فایل تکی فعلاً حداکثر ۵ گیگابایت است (محدودیت باکت).

## نیازمندی‌ها
- Node.js نسخه 20 یا بالاتر
- حساب Supabase برای احراز هویت و ذخیره‌سازی
- یک سرویس میزبانی مانند Vercel

## راه‌اندازی
1. در Supabase یک پروژه بساز.
2. از بخش SQL Editor محتوای `supabase/setup.sql` را اجرا کن.
3. از Project Settings > API، آدرس پروژه و کلید anon/public را بردار.
4. فایل `.env.example` را به `.env.local` تغییر نام بده و مقادیر را وارد کن.
5. در ترمینال پوشه پروژه اجرا کن:
   ```bash
   npm install
   npm run dev
   ```
6. برای انتشار، پروژه را به GitHub و سپس Vercel متصل کن و همان متغیرهای محیطی را در تنظیمات Vercel وارد کن.

## هشدار امنیتی
هرگز کلید `service_role` یا رمزهای مدیریتی Supabase را در کد مرورگر، GitHub یا فایل‌های عمومی قرار نده. این نسخه را تا زمان تکمیل سهمیه سمت سرور و آزمون امنیتی، برای فایل‌های حساس یا استفاده عمومی گسترده منتشر نکن.


## پشتیبانی و درخواست ارتقای فضا
- آیدی پشتیبانی تلگرام: `@MyCloudSuppor`
- لینک تماس: https://t.me/MyCloudSuppor
- کاربر می‌تواند شناسه اختصاصی حساب (Supabase Auth User ID) را از پنل خود کپی کند و برای پشتیبانی بفرستد.
- افزایش فضای دستی توسط مدیر انجام می‌شود و باید به سهمیه فعلی اضافه شود، نه اینکه آن را جایگزین کند.
- در نسخه فعلی، این بخش فقط راه ارتباط و نمایش شناسه را فراهم می‌کند؛ ابزار امن افزایش سهمیه از پنل مدیریت هنوز باید پیاده‌سازی شود.
